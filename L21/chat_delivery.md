## 目标与模型
能明确输入是否可改、索引是否有效、返回值是否新对象；能按位置扫描完成数组/字符串题；能解释操作的时间与额外空间。代码使用Python list表示可变顺序表；不是把list等同NumPy数组或所有语言的定长数组。复杂度采用固定大小元素操作成本模型；任意大整数另计位数。字符串长度按Python字符索引的码点计，不保证等于人眼看到的字形数。

## 一、索引是位置，值不是位置
是什么：长度n的序列有效非负下标为0到n-1；重复值可以占不同位置。list可修改元素，str不可原地改字符。
为什么：很多机试错误来自“最后一个下标=n”或用值代替位置；空输入时没有第一个或最后一个元素。
怎么写：
```python
for i, value in enumerate(values):
    if value == target:
        return i
return -1
```
第一次命中就返回；不存在返回-1，不能把-1直接拿去索引，因为Python中它代表最后一个元素。负下标是从末尾定位的语法，不代表合法的“未找到”位置。
易错点：①range(n+1)访问a[n]越界；②重复值用a.index(value)反查位置会得到首个且引入重复搜索；③空表访问a[0]；④把字符串的可见复合字形当一个下标单位。
何时用：所有按位置搜索、统计、边界检查题。先写n=0、1与目标不存在的行为。

## 二、半开区间统一边界
是什么：[left,right)包含left、不包含right，长度right-left；0<=left<=right<=n时允许空区间。
为什么：相邻区间[0,k)、[k,n)无重叠且覆盖全表；空区间自然由left==right表示，减少+1/-1混乱。
怎么写：
```python
if not 0 <= left <= right <= len(values):
    raise ValueError("区间非法")
total = 0
for i in range(left, right):
    total += values[i]
```
本例只对整数列表求和，线性于区间长度。Python切片a[left:right]会创建新列表；如果只是累计，不需要为了方便先复制切片。切片会容忍某些越界，但这不等于题目接口允许越界，应显式验证。
易错点：①把right也包含进去；②用Python宽容切片掩盖错误参数；③只看sum一行而漏算扫描与切片成本；④使用同一个边界变量混合闭区间和半开区间。
何时用：子数组、局部替换、分段处理，为之后窗口/二分建立统一约定。

## 三、数组修改要看移动，不只看语句数
是什么：顺序表按位置访问通常常数时间，插入/删除中间元素通常要移动后续元素。Python list追加有均摊常数成本，但单次扩容可能更贵。
为什么：反复pop(0)或逐个在开头insert会累计大量移动；一行内置调用并不自动是O(1)。
怎么写：在指定位置pos插入x，允许pos=n；先append腾出一个位置，再从右往左搬：
```python
a.append(x)
for j in range(len(a)-1, pos, -1):
    a[j] = a[j-1]
a[pos] = x
```
例如[2,4,6]在pos=1插入9：先扩展，再将6、4向右移动，结果[2,9,4,6]。从左往右搬会覆盖尚未保存的数据。删除pos则从pos开始将后项向左移，最后pop末项；删除要求0<=pos<n，空表不能删。
易错点：①插入时正向覆盖；②删除后遍历下标跳过元素；③混淆修改原表与返回新表；④“额外空间O(1)”不说明是否包括输出或容器扩容。
何时用：理解数组代价、原地处理题、避免循环内反复头部删除。本课手写搬移帮助理解，日常可使用合适的内置操作。

## 四、字符串不可变，收集片段再连接
是什么：str元素不能通过s[i]=...修改。字符串变换通常产生新字符串；list字符片段可修改，再join得到结果。
为什么：逐次字符串拼接不应无条件宣称线性；教学分析若每次都复制已有前缀，总复制量可能二次。实现优化不能作为一般算法保证。
怎么写：把字符a替换为b，同时保留其他字符：
```python
parts = []
for char in text:
    parts.append(new if char == old else char)
return "".join(parts)
```
n个常数长度片段时，扫描和连接总时间O(n)、输出空间O(n)；若new长为k，结果可能达O(nk)，应按总输出长度分析。题目若限定单字符替换，需明确参数长度。
易错点：①试图修改s[i]；②把split()和split(" ")视为同义，连续空白行为不同；③join混入非字符串；④忽略输出长度和Unicode大小写转换可能改变长度。
何时用：过滤、字符映射、文本格式化。是否保留空格、大小写、标点均以题目为准，不能擅自“清洗”。

## 五、线性扫描靠不变量解释正确性
是什么：遍历过程中保持一个始终成立的事实，说明已处理前缀的结果正确。首次最大值扫描的不变量：处理完a[:i+1]后，best是该前缀最大值，best_index是它首次出现的位置。
怎么写：非空表先设best=a[0]、index=0；从1扫描，只有value>best时更新；相等不更新，因此保留首次位置。空表返回None。
为什么：不变量同时解释初始化、每步保持、最终覆盖全表；比“看起来能跑”更可靠。扫描n-1次比较，时间Θ(n)，固定大小状态为O(1)额外空间。
易错点：①best=0导致全负列表错；②使用>=保留最后一次最大值而不是首次；③用排序求最大值改变输入并增加成本；④只测普通正数，漏掉空表、重复最大值和全负数。
何时用：搜索、极值、连续统计等基础DSA题。统一流程：规格→边界→不变量→实现→验收→时间空间。

## 综合例题
对[3,-2,7,7]：首次最大值为(7,2)；区间[1,3)和为5；复制后在位置1插入9得到[3,9,-2,7,7]；把"a b a"中的a替成x得到"x b x"。各函数明确是否修改输入，examples.py包含空表、重复值、越界和穷举小数组对照验证。
