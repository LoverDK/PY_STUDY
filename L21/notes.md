## 第一段：先把“位置”和“值”分清
想象一排有编号的格子。格子编号是下标，格子里的数是值。对[3,-2,7,7]，下标依次是0、1、2、3。两个7的值相同，位置却不同。
长度n的有效非负下标是0到n-1；插入位置可以额外允许n，表示放到末尾。空列表没有第一个元素，访问a[0]之前必须先处理空输入。
Python list是可变顺序表，不等于NumPy数组，也不等同所有语言的定长数组；str不可原地改字符。本文用固定大小元素的比较/加法模型讨论复杂度，任意大整数需另计位数；Python字符串索引按码点，不保证等于一个完整可见字形。
目标不是背API，而是先写契约：输入是什么、输出什么、能否修改输入、非法位置怎么办。之后每个算法都按这个顺序走。

## 第二段：首次最大值——手里只记住当前冠军
### 问题和第一种念头
输入[3,-2,7,7]，返回(7,2)：最大值7，首次位置2。空表返回None，原列表不变。
可以排序后拿最大值，但这既做了更多工作，也难保留原始首次位置；反复让每个数和所有数比较更没有必要。我们只需要扫描一遍，手里记“目前最大值”和“它第一次出现的位置”。

### 人话流程
1. 空表直接返回None，后续不读第0项。
2. 把第0项当暂时冠军：best=3，index=0。
3. 从下标1开始，逐个挑战best。
4. 只有遇到严格更大的数才换冠军；相等时保留旧位置。
5. 扫完，返回(best,index)。

### 完整实现
```python
def first_max(values):
    if not values:
        return None
    best, index = values[0], 0
    for i in range(1, len(values)):
        if values[i] > best:
            best, index = values[i], i
    return best, index
```
best保存目前最大值，index保存它在原表的位置。循环从1开始，因为第0项已用来初始化。range的右端len(values)不包含在内，所以最后读的是n-1。return在循环外，必须等所有挑战者都看完。

### 一轮不跳地走完
|阶段|i|读到|判断|best/index变化|为什么|
|---|---:|---:|---|---|---|
|初始化|0|3|作为起点|未设置→3/0|先有一个真实候选|
|第1轮|1|-2|-2>3为假|3/0→3/0|冠军不变|
|第2轮|2|7|7>3为真|3/0→7/2|发现更大值|
|第3轮|3|7|7>7为假|7/2→7/2|相等保留首次位置|
|结束|—|—|已看完|返回(7,2)|覆盖全部元素|

### 为什么不会漏
每轮结束后，best都是已看过前缀里的最大值，index是它首次出现的位置。初始化时只看过第0项，这句话成立；新值更大就更新，否则保留，仍成立。最后前缀变成整个列表，所以答案正确。
每轮i增加1，最多走到n-1，必然结束。

### 两个常见错法
- best=0：[-9,-2,-5]里没人能打败0，最后返回一个根本不在表里的值。
- 使用>=：[7,7]会在第1轮更新下标为1，不再是首次位置。
还要避免在循环内提前return，否则只看完第一个挑战者。

### 代价与用途
非空表恰好n-1次值比较，时间Θ(n)，只保存固定数量变量，辅助空间O(1)，返回的二元组也是常数大小。适合一遍扫描极值、保留指定并列规则；不用为了求一个最大值排序。

## 第三段：区间和——先画清左右边界，再累加
### 问题
对[3,-2,7,7]求[1,3)之和，选的是下标1、2，即-2+7=5。左端包含，右端不包含。要求0<=left<=right<=n；合法空区间返回0；非法区间抛ValueError；输入不变。

### 为什么这样约定
[left,right)的长度正好right-left。相邻的[0,k)、[k,n)拼起来没有重复也没有空缺。Python切片会容忍部分越界，但题目约定严格时仍要验证，不能靠“切片没报错”判断正确。

### 人话流程与代码
先验证边界；total从0开始；从left走到right前一个位置，每读一个数就加进去；结束后返回累计值。
```python
def interval_sum(values, left, right):
    if not 0 <= left <= right <= len(values):
        raise ValueError("需要0 <= left <= right <= n")
    total = 0
    for i in range(left, right):
        total += values[i]
    return total
```
total=0是加法的起点，也让空区间自然返回0。不能初始化为values[left]后又从left开始加，否则首项被加两次。循环变量i是读位置，不是被加的值。

### 演练[1,3)
|阶段|i|读到|total变化|动作|
|---|---:|---:|---|---|
|初始化|—|—|未设置→0|尚未处理任何元素|
|第1轮|1|-2|0→-2|纳入左端|
|第2轮|2|7|-2→5|纳入右端前一项|
|结束|3不进入|—|返回5|右端不包含|

不变量：开始处理i时，total等于[left,i)内的和。加入values[i]后它就表示[left,i+1)，直到i到达right，恰好是目标区间。i持续增加，循环有限。

### 易错反例
- range(left,right+1)：上例会额外加下标3的7，结果12。
- 先取a[left:right]再sum：结果可以正确，但多复制了一份区间；只需累计时没必要。
- 不验证left<=right：[3,1)会悄悄返回0，掩盖参数错误。

### 代价与用途
设k=right-left，执行k次加法，时间O(k+1)（非空区间Θ(k)），辅助空间O(1)，输出为一个数。适合一次区间统计；很多次区间查询有更合适的方法，留到相应课再讲。

## 第四段：原地插入——先留空位，再从最右边搬
### 问题和容易写错的办法
给[2,4,6]在pos=1插入9，得到[2,9,4,6]。修改同一个列表，函数返回None。pos允许0到n，非法位置抛错且原表不变。
不能直接a[1]=9，那只是把4覆盖掉。插入要求原来的4、6都保留，必须向右挪。

### 人话流程
1. 在任何修改之前检查位置。
2. 末尾追加一个占位元素，让列表长度从3变4。
3. 从最右侧空位开始，将左邻居复制过来。
4. 一直搬到pos右侧；现在pos可以写9。
占位用value本身即可，但它还不是最终插入位置；中途存在临时重复值是正常的。

### 代码
```python
def insert_at(values, pos, value):
    if not 0 <= pos <= len(values):
        raise ValueError("插入位置越界")
    values.append(value)
    for j in range(len(values) - 1, pos, -1):
        values[j] = values[j - 1]
    values[pos] = value
```
append以后len已经是n+1，所以起点len-1是新末尾下标n。range(...,pos,-1)取n、n-1、...、pos+1，不取pos。每轮目标是j，来源是j-1；最后单独写pos。

### 完整搬移过程
|步骤|j|从哪读→往哪写|操作后列表|原因|
|---|---:|---|---|---|
|初始|—|—|[2,4,6]|尚未修改|
|追加占位|—|末尾写9|[2,4,6,9]|腾出一格|
|搬移1|3|下标2的6→下标3|[2,4,6,6]|先保存最右边元素|
|搬移2|2|下标1的4→下标2|[2,4,4,6]|再搬左邻居|
|放入新值|1|写9|[2,9,4,6]|原元素都已安全挪开|
|结束|—|返回None|同一列表已修改|插入完成|

为什么倒着搬？试试先执行a[2]=a[1]，列表会变成[2,4,4,9]；接着执行a[3]=a[2]读到的是新4，原来的6丢了。倒序保证每次源位置还没被覆盖。
不变量：处理j时，j右侧已经是正确的移后元素，尚待读取的原始前缀保持可用。每轮j减1，直到所有pos到n-1的旧元素都移动一次；再写value，因此不漏原值、顺序不变。
pos=n时没有元素要搬，循环0次，直接写末尾；空表pos=0也成立。

### 易错点与代价
- 正序搬导致丢值，反例见上。
- append后才校验位置：非法调用也改变了原表。
- 把range终点写成pos-1：会多搬一格，pos=0甚至读负下标。
搬移n-pos次，移动部分Θ(n-pos)；计入append的均摊成本，总成本O(n-pos+1)，最坏Θ(n)。手写算法只用常数辅助变量，但Python list某次扩容可能有线性复制与临时存储，不能把“辅助变量常数”当作容器扩容绝无代价的保证。
适合理解顺序表插入成本；实际使用可直接list.insert，但必须知道它在中间插入不是常数工作。

## 第五段：字符串替换——做一张新纸，别改原字符串
### 问题
将"a b a"里的a换为x，结果"x b x"，空格原样保留。old/new各是一个Python字符；原字符串不变。空字符串返回空字符串。

### 思路与流程
字符串不能通过text[i]=new修改。准备一个可追加的片段列表parts；依次读字符，命中old就放new，否则放原字符；最后join。
```python
def replace_char(text, old, new):
    if len(old) != 1 or len(new) != 1:
        raise ValueError("old/new必须各为一个Python字符")
    parts = []
    for char in text:
        parts.append(new if char == old else char)
    return "".join(parts)
```
条件表达式只决定这次放什么，append每个输入字符执行一次；join在循环后执行一次，把片段拼成完整答案。

### 逐字符演练
|轮次|读到|是否等于a|追加什么|parts|
|---|---|---|---|---|
|初始化|—|—|—|[]|
|0|a|是|x|['x']|
|1|空格|否|空格|['x',' ']|
|2|b|否|b|['x',' ','b']|
|3|空格|否|空格|['x',' ','b',' ']|
|4|a|是|x|['x',' ','b',' ','x']|
|结束|—|—|join|结果'x b x'|

每处理k个字符，parts恰好保存原字符串前k个字符按规则转换后的片段；下一步只追加一个对应片段，顺序自然不变。遍历完长度n时，输出覆盖全串且没有多删空格。
易错点：①text[0]='x'会抛TypeError；②split后再join会无意改变空格；③循环内反复join重复构造前缀；④若new不再限单字符，输出长度会改变，复杂度应按输出总长度计算。
时间：n次判断与追加，最后连接n个单字符，O(n+1)。片段列表辅助空间O(n)，返回字符串输出空间O(n)。适合字符过滤、替换、格式化。数字脱敏必须先明确ASCII还是Unicode数字，作业要求只处理0到9。
