你已经会用Python、Pandas、NumPy和Matplotlib处理数据。这一课从一张四行的表开始，介绍机器学习里最先要弄懂的几个词：样本、特征、标签、模型、参数、训练和预测。学完后，你应该能说清程序怎样从数据里选出一条规则，并顺着代码算出每一步的结果。

这一课只需要比较、循环和数组选列。概率论、求导、梯度下降、sklearn、聚类算法和强化学习的更新公式都留在后面。无监督学习和强化学习在这里先认用途。

## 第一段：从一张表里认出输入和答案

下面是四件物品的历史记录，数据是虚构的。

|物品|重量weight|已知类别kind|
|---|---:|---:|
|A|100|0|
|B|120|0|
|C|140|1|
|D|160|1|

以后会来一件新物品，我们只知道它的重量，要猜它属于类别0还是类别1。每行是一件物品，在机器学习里叫一个“样本”。预测时能拿到的重量叫“特征”，历史记录里已经知道的真实类别叫“标签”。

0和1只是类别代号，没有大小或好坏的含义。预测这样的类别叫分类。如果把要预测的东西换成售价，输出就成了一个数值，这类任务叫回归。判断两者时，要看数字表达什么：类别也可以用数字记录。

用你熟悉的DataFrame选列，就能把输入和答案分开：

```python
X = table[["weight"]].to_numpy()
y = table["kind"].to_numpy()
```

X的形状是(4,1)，表示4行物品，每行1个特征。y的形状是(4,)，保存这4件物品各自的标签。两份数据按行对应，X的第几行就要配y的第几个值。

这里用双括号选weight，得到的仍是DataFrame，所以转成数组后保留二维。单括号选kind得到Series，转成数组后是一维。

准备数据时有两处容易出错。把kind也放进X，就会让程序提前看到答案，而未来的新物品只有重量可用。另一个错误是只给X排序，没有同步调整y。例如把重量100配上类别1，输入和答案的对应关系就错了。以后每次建模，都先确认一行代表什么、预测时能拿到哪些输入，以及想预测哪个目标。

## 第二段：给定规则后，程序怎样预测

先用一条现成的规则：重量大于130就预测1，否则预测0。

它接收重量，返回类别，是一个很简单的模型。规则里的130可以调整，这个数叫参数。这一步由我们给定130，程序只负责照着计算。

从第一件物品开始，取出重量，与130比较，把预测存起来，然后处理下一件：

```python
threshold = 130.0
predictions = []
for weight in [100., 120., 140., 160.]:
    prediction = 1 if weight > threshold else 0
    predictions.append(prediction)
```

predictions最初是空列表。每次循环只追加一个预测，原来的重量数据保持不动。

|步骤|读到重量|是否>130|添加的预测|已有预测|
|---:|---:|---|---:|---|
|1|100|否|0|[0]|
|2|120|否|0|[0,0]|
|3|140|是|1|[0,0,1]|
|4|160|是|1|[0,0,1,1]|

四个预测恰好与真实标签[0,0,1,1]相同，所以错分0件。若把阈值改成110，重量120的物品就会被预测为1，而它的真实类别是0，于是错1件。

比较符号要看仔细：本课用的是>，因此重量恰好等于130时预测0。写成>=会改变这个边界上的结果。两种规则都可以定义，但讲义、代码和验收必须一致。

也不能把y直接复制出来当预测。那样当然能在这张表上全部答对，可遇到没有标签的新物品时就无法计算了。我们需要的是一条确定参数后、只凭新输入就能给出结果的规则。

## 第三段：用历史数据选择规则，理解训练

现在给程序三个候选阈值：110、130、150。候选由题目给定，你暂时不用考虑怎样生成它们。程序要做的是分别试一遍，看哪个错得最少。

1. 先取110，按上一段的方法预测四件物品。
2. 逐项对照真实标签，数出错分数量。
3. 再试130和150，各自重新计数。
4. 保留错分最少的阈值。
5. 固定选中的阈值，用它预测新物品。

|候选阈值|100预测|120预测|140预测|160预测|错在哪里|错分数|
|---:|---:|---:|---:|---:|---|---:|
|110|0|1|1|1|120真实为0|1|
|130|0|0|1|1|无|0|
|150|0|0|0|1|140真实为1|1|

程序选中130，因为它在这四条记录上错得最少。利用历史输入和标签选择参数的这个过程，就叫训练。我们事先规定了可选规则和比较标准，程序根据数据完成选择。

把刚才的比较写成数学也很简单。用n表示训练样本数，本例n=4；errors(t)表示阈值为t时错分多少件。那么：

训练错误比例 = errors(t) / n

三个候选的错误比例依次是1/4=0.25、0/4=0、1/4=0.25。“损失”是衡量错得多严重的数，本例就用错分比例。我们的目标是在三个候选里选出这个比例最小的一个。由于它们比较的是同一批样本，直接比错误数量也能得到相同结果。

代码用best_threshold记住当前最好的阈值，用best_errors记住它的错误数。best_errors初始设为5，比这四条记录最多可能出现的错误数4还大，因此第一个候选一定能先存进去。后面只有遇到错误更少的候选才替换。

这样，处理完前k个候选时，程序始终记着其中错分最少的那个。三个候选都处理完，就得到了这个候选集合中的最优值。这个结论的范围只有给定的三条规则。

训练结束后，还要留意两个问题。第一，若又根据新样本的真实答案修改阈值，这些样本就参与了选择，不能再用它们做独立检验。第二，训练错分0件，并不保证未来也错分0件。这里仅有四条虚构记录，未来可能出现重量140却属于类别0的物品，重量本身也未必足够区分类别。

有历史输入和对应答案，希望从中选择预测规则时，就可以考虑监督学习。这个四样本例子只用来说明它怎样工作。

## 第四段：无监督学习和强化学习用来做什么

刚才的监督学习能拿到每件物品的真实标签。垃圾邮件识别也类似：邮件是输入，“垃圾”或“正常”是标签。面积等特征对应房价，则是回归任务。“监督”在这里指标签提供学习信号。

如果只有客户的消费次数和消费金额，没有现成的客户类别，却想看看哪些客户相似，就会用到无监督学习。它可以帮助探索分组，但分出来的编号0、1并没有天然的业务含义，不能直接命名为“好客户”和“差客户”。没有标签时仍然需要明确目标、检查结果。具体的聚类方法和代码留到L70。

强化学习处理的是行动会影响后续处境的问题。例如机器人走迷宫：当前位置是状态，向左或向右走是动作，到达出口可以得到奖励。系统要根据这些反馈学习怎样行动，考虑一串行动之后的结果。本课先认识这些词，Q值和折扣回报在后续AI阶段再讲。

这里也有两种常见误解：某一步奖励高，不保证整条路线的结果更好；把普通分类的答案改叫奖励，也不足以构成一个强化学习过程。

|方式|你拿到什么|希望做什么|本课要求|
|---|---|---|---|
|监督|输入与标签|预测未知标签|走通一个四样本例子|
|无监督|输入，没有目标标签|探索数据结构|能说用途和区别|
|强化|行动后的反馈|学习行动策略|能认出状态/动作/奖励|

目前先把监督学习的例子走通。后面学习具体方法时，再回到这张表确认它在解决哪一类问题。

## 第五段：对照完整代码，把每一步接起来

第一次阅读时可以分开运行。第1段看X和y从哪里来；第2段对照四件物品的预测；第3段再看程序怎样比较候选。末尾的断言是自检，可以读完主过程后再看。

examples.py中的完整代码如下：

```python
"""L61：先运行第1段，再读第2段，最后读第3段。数据均为虚构教学数据。"""
import numpy as np
import pandas as pd

# 第1段：从熟悉的DataFrame出发。一行是一件物品，不是一个特征。
table = pd.DataFrame({
    "weight": [100.0, 120.0, 140.0, 160.0],
    "kind": [0, 0, 1, 1],
})
X = table[["weight"]].to_numpy()  # 双括号保留列：4行1列
y = table["kind"].to_numpy()      # 单列标签：长度4
print("第1段：数据")
print(table.to_string(index=False))
print("X形状:", X.shape, "y形状:", y.shape)

# 第2段：先使用人为给定的规则，不做训练。
threshold = 130.0
predictions = []
print("第2段：固定规则，weight > 130预测1，否则0")
for i in range(len(y)):
    weight = X[i, 0]
    prediction = 1 if weight > threshold else 0
    predictions.append(prediction)
    print(i, weight, int(y[i]), prediction)
print("固定规则预测:", predictions)

# 第3段：比较三条题目给定的候选规则，这才是本例的“学习”。
candidates = [110.0, 130.0, 150.0]
best_threshold = None
best_errors = len(y) + 1
print("第3段：用训练数据选规则")
for candidate in candidates:
    current_predictions = []
    errors = 0
    for i in range(len(y)):
        prediction = 1 if X[i, 0] > candidate else 0
        current_predictions.append(prediction)
        if prediction != y[i]:
            errors += 1
    print("候选:", candidate, "预测:", current_predictions, "错分:", errors)
    if errors < best_errors:
        best_threshold = candidate
        best_errors = errors
print("学到的阈值:", best_threshold)

# 阈值固定后，预测新输入。这里没有新样本的真实标签，不报告测试准确率。
new_weights = [110.0, 150.0]
new_predictions = []
for weight in new_weights:
    new_predictions.append(1 if weight > best_threshold else 0)
print("新输入:", new_weights, "预测:", new_predictions)

# 以下是可选自检区，不属于首次阅读主线。
assert X.shape == (4, 1) and y.shape == (4,)
assert predictions == [0, 0, 1, 1]
assert best_threshold == 130.0 and best_errors == 0
assert new_predictions == [0, 1]
assert int(130.0 > best_threshold) == 0  # 等于阈值时按约定预测0
assert [int(v > 130.0) for v in []] == []
assert [int(v > 130.0) for v in [140.0]] == [1]
assert [int(v > 130.0) for v in [120.0, 120.0, -1.0]] == [0, 0, 0]
assert np.array_equal(y, np.array([0, 0, 1, 1]))
print("本课数值与适用边界自检通过")

```

numpy用在最后的数组相等检查，pandas用来创建数据表，主过程没有引入新库。

循环里的X[i,0]取第i件物品的第0个特征，y[i]取同一件物品的真实类别。candidates保存三个允许尝试的阈值，candidate是当前这一轮试的值。

每换一个候选，errors都要重新从0开始，current_predictions也要重新建成空列表。否则，上一条规则的错分和预测就会混进下一条规则的结果里。best_threshold和best_errors则保留到下一轮，用于比较当前候选是否更好。

选好130后，程序用它处理new_weights里的110和150，得到[0,1]。这两条新输入没有提供真实标签，所以这里只能报告预测，不能报告测试准确率。

回头看，三个词分别对应三件事：根据历史数据选择参数叫训练；固定参数后计算新输入叫预测；拿预测与独立真值比较质量叫评估。L62接着讲评估。

程序只打印结果，不创建图或写文件。如果你想用熟悉的scatter看看这四个点，可以自行在notebook中画，画图不是本课必做项。

这段代码已经实际运行过：X形状为(4,1)，y形状为(4,)；三个候选错分数为[1,0,1]，选中130；新输入[110,150]得到预测[0,1]。等于阈值、空预测、单样本、重复重量和负数的比较规则也通过了自检。负重量只用于检查代码边界，不是合理的业务样本。

复杂度可以暂时略读。若有m个候选、n条样本，每个候选都扫一遍样本，时间为O(mn)。每轮保存n个预测，辅助空间为O(n)；最后对k个新输入产生k个预测，输出空间为O(k)。本例m=3、n=4，先读懂循环即可。
