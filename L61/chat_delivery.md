## 第一段：先从你会看的表格开始

我们有四件物品的历史记录。数据完全虚构，只用来说明概念。

|物品|重量weight|已知类别kind|
|---|---:|---:|
|A|100|0|
|B|120|0|
|C|140|1|
|D|160|1|

要做的事情是：未来来一件只知道重量的新物品，猜它属于类别0还是类别1。每行是一条记录，机器学习里叫一个“样本”；预测时能拿到的重量叫“特征”；历史记录里的真实类别叫“标签”。

类别0/1只是代号，0不是更差，1不是更重的“数量”。这叫分类。若目标换成售价，输出是一个数值，就叫回归。不要仅凭标签写成数字就判断是回归。

你已经会用DataFrame保存表格。现在只是规定两份不同用途的数据：
```python
X = table[["weight"]].to_numpy()
y = table["kind"].to_numpy()
```
X是输入，形状(4,1)：4行物品、每行1个特征；y是答案，形状(4,)：4个标签，顺序必须与X对应。
双括号保留DataFrame的列维度；单括号得到Series，再转换为一维数组。这里不需要任何模型知识。

易错1：把kind也放进X，相当于让预测器先看到要猜的答案。本题未来只有重量，不能提供真实类别。
易错2：把X排了序却没同步重排y，例如100被配成类别1，程序会学错对应关系。
何时用：每次机器学习建模前，先说清“一行是什么、输入是什么、目标是什么”。

## 第二段：先会“用规则”，再谈“学规则”

先由老师给一条规则：重量大于130，预测1，否则预测0。
这条规则就是一个极简单的模型：输入重量，输出类别。130是规则里可以调整的数，叫参数。本段130是人给的，程序还没有学习。

流程：取一件物品 → 比较重量和130 → 写下预测 → 处理下一件。
```python
threshold = 130.0
predictions = []
for weight in [100., 120., 140., 160.]:
    prediction = 1 if weight > threshold else 0
    predictions.append(prediction)
```
if/else只是在按规则计算；predictions依次存每个输出，不改变原始重量。

|步骤|读到重量|是否>130|添加的预测|已有预测|
|---:|---:|---|---:|---|
|1|100|否|0|[0]|
|2|120|否|0|[0,0]|
|3|140|是|1|[0,0,1]|
|4|160|是|1|[0,0,1,1]|

真实标签[0,0,1,1]与预测相同，错分0件。如果阈值换成110，120就会被预测成1，错1件。
易错1：把>写成>=，重量恰等于130时会改变结果。两种规则都能定义，但必须说清并前后一致。
易错2：把真实标签y当成预测结果直接返回，虽然会得到“满分”，却根本不能预测未知标签。
何时用：参数已经确定后，对新输入计算输出，这就叫预测。

## 第三段：让数据帮我们选130，理解一次“训练”

刚才你可能问：为什么是130？现在题目只允许三个候选110、130、150，让程序比较它们。
这些候选由题目给定，不要求你自己推导候选生成方法。

流程：
1. 取候选110，按第2段的办法预测四件物品。
2. 与历史真实标签比较，数错几个。
3. 对130和150重复同样的事。
4. 保留错得最少的候选。这个选择过程叫训练。
5. 以后固定选中的数，再对新物品预测。

|候选阈值|100预测|120预测|140预测|160预测|错在哪里|错分数|
|---:|---:|---:|---:|---:|---|---:|
|110|0|1|1|1|120真实为0|1|
|130|0|0|1|1|无|0|
|150|0|0|0|1|140真实为1|1|

所以数据帮我们选出130。不是程序突然有了理解能力，而是我们规定了可选规则与比较标准，它按数据选择参数。

用最少的数学把同一件事写清：n表示训练样本数，本例n=4；errors(t)表示阈值为t时错分数量。
训练错误比例=errors(t)/n。本例三项是1/4=0.25、0/4=0、1/4=0.25。
“损失”就是衡量错得多严重的数；本例只用错分比例，不引入其他损失函数。目标是在给定三个候选中选比例最小者。样本数相同，直接比较错误数也会选中同一个阈值。

代码中best_errors初始为5，比可能出现的最大错误数4还大，保证第一个候选会先被记住。每次只在errors更小时替换。处理完前k个候选，best保存其中错误最少者；候选有限，最后得到三个候选中的最优，不代表所有模型里的最优。

易错1：选完参数后又根据新样本的真实答案调整它，那就不能把这些新样本当独立检验。
易错2：认为0错代表真实世界也0错。这里只看到4条虚构数据；未来可能有重量140却属于0的物品，重量也可能根本不够区分类别。
何时用：已经有历史输入和真实答案，希望从中选择预测规则，这就是监督学习的一种最小示意。

## 第四段：认识另外两种学习，不在第一课实现它们

监督学习中，每条训练输入都有相应标签。邮件→垃圾/正常是分类；面积等特征→房价是回归。这里“监督”指标签提供学习信号，不是有人盯着电脑。

无监督学习中，没有现成的目标标签。例如只有客户消费次数和消费金额，希望看看哪些客户相似。它可以探索分组，但分组编号不能自动命名为“好客户/差客户”。本课知道其用途即可，L70再学聚类与具体代码。
易错1：没有标签不等于没有目标或不用检查结果；易错2：簇0/1不是天然的业务真实类别。

强化学习中，行动影响后续处境，系统根据奖励学习怎样行动。例如机器人走迷宫：所在位置是状态，向左/右走是动作，到达出口可以给奖励。它关心一串行动之后的结果，本课不要求计算Q值或折扣回报；后续AI阶段再展开。
易错1：把“这步奖励高”理解成“整条路线一定更好”；易错2：把普通分类答案换个名字叫奖励，就说已经完成强化学习。

|方式|你拿到什么|希望做什么|本课要求|
|---|---|---|---|
|监督|输入与标签|预测未知标签|走通一个四样本例子|
|无监督|输入，没有目标标签|探索数据结构|能说用途和区别|
|强化|行动后的反馈|学习行动策略|能认出状态/动作/奖励|

这张表是地图，不是三套算法实现清单。先走通监督学习，再逐渐学更多方法。

## 第五段：完整代码，按三个台阶阅读

先只运行第1段，确认X/y是什么；再运行第2段，逐项对照预测；最后运行第3段，看错分比较。不要第一次就从头读到断言区。
完整代码如下，与examples.py相同：

```python
"""L61：先运行第1段，再读第2段，最后读第3段。数据均为虚构教学数据。"""
import numpy as np
import pandas as pd

# 第1段：从熟悉的DataFrame出发。一行是一件物品，不是一个特征。
table = pd.DataFrame({
    "weight": [100.0, 120.0, 140.0, 160.0],
    "kind": [0, 0, 1, 1],
})
X = table[["weight"]].to_numpy()  # 双括号保留列：4行1列
y = table["kind"].to_numpy()      # 单列标签：长度4
print("第1段：数据")
print(table.to_string(index=False))
print("X形状:", X.shape, "y形状:", y.shape)

# 第2段：先使用人为给定的规则，不做训练。
threshold = 130.0
predictions = []
print("第2段：固定规则，weight > 130预测1，否则0")
for i in range(len(y)):
    weight = X[i, 0]
    prediction = 1 if weight > threshold else 0
    predictions.append(prediction)
    print(i, weight, int(y[i]), prediction)
print("固定规则预测:", predictions)

# 第3段：比较三条题目给定的候选规则，这才是本例的“学习”。
candidates = [110.0, 130.0, 150.0]
best_threshold = None
best_errors = len(y) + 1
print("第3段：用训练数据选规则")
for candidate in candidates:
    current_predictions = []
    errors = 0
    for i in range(len(y)):
        prediction = 1 if X[i, 0] > candidate else 0
        current_predictions.append(prediction)
        if prediction != y[i]:
            errors += 1
    print("候选:", candidate, "预测:", current_predictions, "错分:", errors)
    if errors < best_errors:
        best_threshold = candidate
        best_errors = errors
print("学到的阈值:", best_threshold)

# 阈值固定后，预测新输入。这里没有新样本的真实标签，不报告测试准确率。
new_weights = [110.0, 150.0]
new_predictions = []
for weight in new_weights:
    new_predictions.append(1 if weight > best_threshold else 0)
print("新输入:", new_weights, "预测:", new_predictions)

# 以下是可选自检区，不属于首次阅读主线。
assert X.shape == (4, 1) and y.shape == (4,)
assert predictions == [0, 0, 1, 1]
assert best_threshold == 130.0 and best_errors == 0
assert new_predictions == [0, 1]
assert int(130.0 > best_threshold) == 0  # 等于阈值时按约定预测0
assert [int(v > 130.0) for v in []] == []
assert [int(v > 130.0) for v in [140.0]] == [1]
assert [int(v > 130.0) for v in [120.0, 120.0, -1.0]] == [0, 0, 0]
assert np.array_equal(y, np.array([0, 0, 1, 1]))
print("本课数值与适用边界自检通过")

```

代码细读：
- numpy用于最后检查数组是否相等，pandas用于创建熟悉的数据表；主过程没有新库。
- X[i,0]指第i件物品的第0个特征，y[i]是同一件的真实类别。
- candidates是我们允许尝试的三个数；candidate是本轮试的一个数。
- errors每轮重置为0，因为每条候选规则要单独计错。
- best_threshold保存目前最好的规则参数；best_errors保存它错几件。
- current_predictions每轮重新创建，防止把上一个候选的结果接到本轮后面。
- new_weights没有真实标签。程序仍能预测[0,1]，但不能据此报告测试准确率。
- 这些参数来自历史数据的选择，叫训练；固定参数后的计算，叫预测；拿预测与独立真值比较质量，叫评估。L62会接着讲评估。
- 本例只打印，没有创建图或写文件。画图已有基础的同学可自行在notebook用scatter查看四个点，但不是必做。

实测结果：X为(4,1)、y为(4,)；三个候选错分[1,0,1]，选130；新输入[110,150]预测[0,1]；等于阈值、空预测、单样本、重复重量、负数按比较规则均通过自检。负重量只是代码边界值，不是合理业务样本。
代价补充（不要求首次掌握）：m个候选各扫n件，时间O(mn)；当前每轮保存n个预测，辅助空间O(n)，最终新预测k个占输出空间O(k)。这里m=3、n=4，不需要为了优化改变这段入门代码。
