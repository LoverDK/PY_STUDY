## 第一段：机器学习到底是在“学”什么
先看一个具体任务：根据水果重量，预测品种类别。每行一颗水果；重量是输入特征x，已知品种是目标y。我们手工写if重量>某数是规则编程；让程序从历史带标签样本里选出阈值，才是在这个简化例子里学习参数。
X通常是二维“样本数×特征数”，y是与每行对应的目标。一列特征仍要写成[[1],[2],[3],[4]]，形状(4,1)，而不是把它当四列特征。
任务地图：
|你能拿到什么|想做什么|学习方式|例子|
|---|---|---|---|
|X和已知y|预测新样本的y|监督学习|类别、房价|
|只有X|发现结构/压缩表示|无监督学习|客户分组、降维|
|行动后环境反馈奖励|学会选择一串行动|强化学习|路径决策、控制|
分类目标是离散类别；回归目标是数值。数字形式的y不自动等于回归，例如0/1是类别编码。强化学习中的奖励不是每个状态的标准动作标签。
怎么做：先把“业务想知道什么”写成输入/输出，再看数据能否在预测时获得。不能先挑一个模型再硬套任务。
易错：①把订单号当有意义数值特征；②把未来信息当预测时已知；③认为所有AI都是深度学习；④把监督理解为有人实时盯着电脑。
适用：所有项目开题时，先定任务与信息边界。

## 第二段：监督学习——从带答案的例子中选规则
### 问题
训练重量[1,2,3,4]，标签[0,0,1,1]，训练一个“x>t预测1，否则0”的小分类器。之后预测新重量1.2和3.2。输入不能包含新样本的真实答案。
固定“阈值从小到大”的规则族，候选只用相邻不同训练值的中点1.5、2.5、3.5；示例约定并列时选较小阈值。本模型不是通用分类器：类别方向反过来、数据同值、复杂边界时可能表现不好。
### 人话流程
1. 将训练输入的不同值排序。
2. 找相邻值的中点，作为允许尝试的阈值。
3. 对每个阈值，在训练集上逐个预测、数错几个。
4. 保留训练错误最少的阈值。
5. 冻结阈值，之后predict只比较新重量，不重新看答案。
### 完整实现
```python
def fit_threshold(xs, ys):
    if not xs or len(xs) != len(ys):
        raise ValueError("训练输入须非空且长度一致")
    if any(y not in (0, 1) for y in ys):
        raise ValueError("标签须为0或1")
    unique = sorted(set(xs))
    if len(unique) < 2:
        raise ValueError("本教学模型至少需要两个不同输入")
    candidates = [(a+b)/2 for a,b in zip(unique, unique[1:])]
    best_t, best_errors = None, len(xs)+1
    trace = []
    for t in candidates:
        predictions = [int(x > t) for x in xs]
        errors = sum(p != y for p,y in zip(predictions, ys))
        trace.append((t, predictions, errors))
        if errors < best_errors:
            best_t, best_errors = t, errors
    return best_t, trace
```
best_errors初始比任何可能错误数都大，保证第一次能选中。候选已升序，更新用<，所以错误并列保留较小t。trace只是教学记录，正常模型只需保留参数best_t。
### 完整演练
|候选t|依次预测x=1,2,3,4|与[0,0,1,1]比较|保留参数|
|---:|---|---:|---|
|1.5|[0,1,1,1]|错1个|1.5|
|2.5|[0,0,1,1]|错0个|改为2.5|
|3.5|[0,0,0,1]|错1个|仍为2.5|
最终t=2.5；新重量1.2>2.5为假，预测0；3.2>2.5为真，预测1。示例另设测试标签[0,1]，只在预测完成后核对，不能用来挑阈值。
正确性：检查完前k个候选，best始终是它们中错误最少且最先出现的；枚举完后得到“本候选集合”最优参数，不保证全世界模型最优。候选及样本循环都有有限长度，必然停止。
代价：n个样本、最多n-1个候选，朴素搜索O(n²)时间；本实现保存每个候选全部预测，trace空间O(n²)。去掉trace可使搜索辅助空间O(n)（排序/候选/预测），最终模型只存阈值O(1)。单个新样本预测O(1)，m个输出O(m)。
sklearn对应工作流是model.fit(X_train,y_train)再model.predict(X_new)。examples.py另用max_depth=1的决策树做API体验；算法内部另在后课详讲，不把库调用假装成已推导完整决策树。
易错：①把训练集0错误当泛化保证；②用测试答案反复选t；③predict时重新fit；④把0/1类别编号当连续数量。
何时用：有历史标注、要预测同类新样本的分类或回归任务。房价回归和这里的阈值分类不是同一个输出问题。

## 第三段：无监督学习——没有标准答案，先按相似性找结构
### 问题
有四位客户的简化消费指标[0,2,4,6]，没有“高价值/低价值”标签。给定两个初始中心[0,6]，先做一轮分配和均值更新。这是一轮KMeans风格演示，不是完整KMeans训练。
### 流程与代码
1. 每个点分别算到两个中心的距离。
2. 选最近中心，等距离选编号更小的簇。
3. 每簇用分到的点计算新均值；若空簇保留旧中心（本演示明确规定）。
```python
def cluster_round(points, centers):
    if not centers:
        raise ValueError("中心不能为空")
    groups = [[] for _ in centers]
    labels, trace = [], []
    for x in points:
        distances = [abs(x-c) for c in centers]
        group = min(range(len(centers)), key=lambda j: distances[j])
        labels.append(group)
        groups[group].append(x)
        trace.append((x, distances, group))
    updated = [
        sum(group)/len(group) if group else centers[j]
        for j,group in enumerate(groups)
    ]
    return labels, updated, trace
```
本次所有点都按同一份旧中心分配，结束后才更新，不能每处理一个点就修改中心，那是另一个过程。
### 一轮演练
|点x|到0距离|到6距离|分到哪个簇|
|---:|---:|---:|---:|
|0|0|6|0|
|2|2|4|0|
|4|4|2|1|
|6|6|0|1|
簇0=[0,2]，新中心1；簇1=[4,6]，新中心5。若再用[1,5]分配，本例标签仍[0,0,1,1]，更新后中心不变；真实训练需定义迭代停止条件，本课不展开。
为什么：每个点确实选择当前中心中最小距离；均值更新仅表示各簇平均位置，不证明找到全局最佳聚类。簇号0/1只是编号，交换中心顺序可以交换编号，却不改变实际分组。
代价：n点k中心，一维距离分配O(nk)，分组和均值O(n+k)；本trace也保存n×k距离，空间O(nk+n+k)。在高维需再乘距离计算维数。
易错：①把簇0直接命名“差客户”；②拿簇编号与某标签直接相等比较当准确率；③忘记量纲改变距离；④忽略空簇。
何时用：探索分组、压缩和相似性结构。无标签不代表没有数据质量问题或不用评估。

## 第四段：强化学习——行动会改变后面的处境
### 场景
三格走廊状态0、1、2，2为终点。动作R向右。到终点奖励1，其余0。我们看几条固定演示经历如何更新Q(s,a)，不是让智能体自动探索训练。
Q值可理解为“在这个状态做这个动作，对未来回报的当前估计”，不是环境颁发的正确答案。
更新：
Q新=Q旧+α×[r+γ×下一状态最大Q−Q旧]。终点之后没有未来项，目标就是r。本课α=0.5，γ=0.9，所有初始Q为0。
### 人话流程
读一条(状态,动作,奖励,下一状态,是否终止)经历；查旧Q；算下一步估计（终止则0）；算目标；朝目标走α比例；只更新当前状态动作。
```python
def q_update(q, state, action, reward, next_state, done,
             alpha=0.5, gamma=0.9):
    old = q.get((state, action), 0.0)
    future = 0.0 if done else max(
        q.get((next_state, a), 0.0) for a in ("L","R")
    )
    target = reward + gamma*future
    new = old + alpha*(target-old)
    q[(state, action)] = new
    return old, future, target, new
```
get默认0是本演示的初始化约定；done决定是否截断未来。动作集合固定L/R，未访问动作也按0，不保证适用于所有环境设置。
### 四次经历，一步不跳
|次序|经历|旧Q|future|目标|新Q|
|---:|---|---:|---:|---:|---:|
|1|0,R,0,1,非终止|0|0|0|0|
|2|1,R,1,2,终止|0|0|1|0.5|
|3|0,R,0,1,非终止|0|0.5|0.45|0.225|
|4|1,R,1,2,终止|0.5|0|1|0.75|
奖励先改进“从1向右”的估计，再通过后续经历传回状态0。不是第一次经过就知道整条路价值。
代价：动作数A时一次更新O(A)，本例A=2视为常数；表存已访问状态动作，空间O(访问对数)，记录t条trace另占O(t)。
易错：①终点仍加入未来Q，重复计算后续不存在回报；②把即时奖励当长期价值；③只展示四次更新就宣称学会最优策略；④忽略探索与样本覆盖。本例没有实现探索/动作选择/完整环境，不能说完成强化学习训练。
何时用：当前动作会影响后续状态、目标是累计回报的序列决策。普通有标签分类不因“答对给1分”就自动成了完整强化学习问题。

## 第五段：从地图到第一次实验，要知道“看到了什么证据”
监督看目标预测质量；无监督看结构与任务解释，不能只看簇号；强化学习看策略的累计回报及交互约束，不能只看某一次奖励。
训练是用允许的数据确定参数；预测是参数固定后对新输入计算；评估是拿预测或行为结果与任务目标核对。数据划分、分类指标和泄漏将在L62细讲，本课先建立“新数据不能参与挑答案”的底线。
完整例程顺序：列X/y形状→拟合阈值并打印三个候选→对两条新输入预测→仅作检查的标签核对→无标签分配和中心更新→四次Q更新→sklearn fit/predict体验。不是把三个过程混成一个模型。
易错：①输入形状错位，X每行没对应y；②把演示小样本满分写成真实能力；③把固定奖励轨迹当已训练策略；④依赖随机结果却无复现设置。实际数据权限、分布和目标都需明确。


## 理论加深：把三个例子写成明确的学习目标
### 监督：从规则集合中选择参数
设训练样本为D={(x_i,y_i)}，本课预测函数h_t(x)=1[x>t]，方括号表示条件成立为1、否则0。t是要学的参数，不是输入样本；训练集是挑参数的材料。
分类的0–1损失为L(h_t(x_i),y_i)=1[h_t(x_i)≠y_i]。本课在三个候选中最小化平均训练损失：
R_train(t)=(1/n)Σ_i L(h_t(x_i),y_i)。
这里n=4，三个候选损失分别为1/4、0/4、1/4，故选2.5。程序数错分个数没有除n，但n固定时最小化个数与平均损失得到同一参数。
这叫在允许规则集合里做经验风险最小化的一个极简实例。它没有说明未来数据一定相同，也没有证明训练最优等于泛化最优。我们至少需要历史样本与未来任务有足够相关性、标签含义一致；分布漂移、偏差标注、漏掉关键特征都可能让规则失效。L62开始系统学习划分和指标。
分类的标签空间是离散集合，例如{0,1}；回归目标可取连续量，例如房价，可选择平方误差(y_hat-y)^2等损失。损失函数要与任务相配，不能把类别编号之间的差当成自然距离。训练“学参数”，推断“用参数”，评估“看未用于选参数的数据上的表现”。

### 无监督：分组不是自动发现业务真相
一维KMeans的常见目标可写为J=Σ_i (x_i-μ_{z_i})²，其中μ_j是簇j中心，z_i是样本i的簇编号。这是几何紧凑性目标，不是“客户价值真实类别”的保证。
固定中心时，选最近中心最小化该点平方距离；一维非负距离与其平方排序相同，所以代码用abs也能作相同分配。固定分组时，组内平方差之和对中心求导得到2Σ(μ-x_i)=0，所以μ等于组内均值；这是本轮更新取均值的理论理由，不是随意平均。
初始中心[0,6]、分组[0,0,1,1]，目标J=0²+2²+(-2)²+0²=8；更新到[1,5]后，J=(-1)²+1²+(-1)²+1²=4。此次目标下降，但不推出全局最优。真实迭代受初始化、簇数k、量纲和非球形分布影响。
无标签不意味着没目标，也不等于不需评估。可以检查结构稳定性、距离指标和业务解释；详细聚类指标留L70。不得用本例标签0/1与监督标签直接比较“准确率”。

### 强化：目标是累计回报，不是眼前奖励
把环境写成状态s、动作a、转移到下一状态s'、奖励r、终止标记done。策略π决定在状态如何选动作。常见折扣回报G_t=r_t+γr_(t+1)+γ²r_(t+2)+...，γ∈[0,1]控制未来奖励折扣；γ不是学习率。
例如奖励[0,1]、γ=0.9，起点这条轨迹的回报是0+0.9×1=0.9，不是只看当前0就判它没价值。Q(s,a)估计在状态s选择a之后的折扣回报；本例用bootstrap目标r+γmax_a' Q(s',a')更新估计。α是向目标靠近的比例，和γ的作用不同。
在第3条经历，未来估计0.5，目标0.45；旧值0，α=0.5，更新只走一半到0.225，并非直接改成0.45。终止经历目标只有奖励，不再从终点延伸未来。
通常需要状态信息足以表达后续决策、环境反馈定义清晰，并通过探索与足够样本学习。本课只演示固定经历的表格更新，没有学习动作选择，没有证明收敛或最优，也不是用sklearn训练RL。

## 代码细读：知道每一步属于哪一阶段
fit_threshold的xs是n个一维数值，ys是n个标签。sorted(set(xs))生成唯一有序取值，zip(unique,unique[1:])形成相邻对；每一对中点给一个候选。predictions长度n，与ys逐项对齐，errors才有意义。best_t是最终模型，trace是教学记录，后者不能带进模型空间的宣称中。
cluster_round的groups是k个独立列表；用[[]]*k会共享同一列表而混组。labels长度n，updated长度k。min的key按各中心距离选索引，距离并列时沿索引顺序保留较小者。整个分配循环后再计算updated，保持一轮中中心固定。
q_update接受可变字典q，按契约原地更新一个键。old是修改前估计，future是下一状态动作集合的最大估计，target是本条经历给出的学习目标，new是更新后的值。q_demo返回最终字典和每次真实计算的trace；打印浮点值时允许容差而非要求所有小数精确二进制表示。
### sklearn体验的可独立运行代码
```python
from sklearn.tree import DecisionTreeClassifier

X_train = [[1.0], [2.0], [3.0], [4.0]]  # 4行样本、1列特征
y_train = [0, 0, 1, 1]                 # 与4行一一对应
X_test = [[1.2], [3.2]]                # 2行新样本、仍是1列特征
model = DecisionTreeClassifier(max_depth=1, random_state=0)
model.fit(X_train, y_train)
prediction = model.predict(X_test)
print(prediction.tolist())             # [0, 1]
```
max_depth=1限制树深，让本例只体验一个简单分界；random_state用于复现估计器可能用到的随机行为，不代表设置种子就保证真实泛化。fit根据训练X/y建立树，predict返回两个类别，不在此时修改训练参数。树的实际候选搜索与准则并不等同本课手写0–1损失枚举，不能将两者内部当成完全相同算法；详细原理在L68。
这两条测试记录仅用于展示工作流，数量太少，不能评价真实部署能力。完整examples.py把手写流程、库调用和边界断言放在一起，主程序只打印，不下载数据或写文件。
