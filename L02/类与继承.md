# 类与继承（细讲）

对应 L02 练习 3。这一份把类、对象、`self`、继承按这道题走一遍。

## 1. 类是图纸，对象是做出来的那一个

`Person` 是图纸：每个人都有名字，都会自我介绍。

```python
p = Person("Qiu")
```

`p` 才是一个具体的人。同一张图纸可以做出很多个，各自记着自己的名字：

```python
a = Person("Qiu")
b = Person("Li")
```

`a.name` 是 `"Qiu"`，`b.name` 是 `"Li"`。改 `a` 不会碰到 `b`。

## 2. 先把 Person 写全

```python
class Person:
    def __init__(self, name):
        self.name = name

    def hello(self):
        return f"I am {self.name}"
```

`class Person:` 从这里开始定义图纸。类名习惯每个单词首字母大写。

`__init__` 在创建对象时自动执行。写 `Person("Qiu")` 时，Python 进入这个函数，参数 `name` 收到 `"Qiu"`。平时不要自己再调用一次 `__init__`。

`self` 就是「正在操作的这个对象」。`self.name = name` 把 `"Qiu"` 存在这个对象身上。之后写 `p.name`，取到的就是这次存进去的值。

`hello` 是这个对象能做的事。调用写成 `p.hello()`，圆括号里不用再写 `p`。Python 会把 `p` 自动填进 `self`。所以：

```python
p = Person("Qiu")
print(p.hello())   # I am Qiu
```

`p.hello()` 进入函数时，`self` 就是 `p`，`self.name` 就是 `"Qiu"`。换成 `b.hello()`，`self` 就是 `b`。

方法定义里第一个参数始终写 `self`。调用时不写。

## 3. 子类：Student 也是 Person

学生是一种人，多一个学号。括号里写父类：

```python
class Student(Person):
    def __init__(self, name, sid):
        super().__init__(name)
        self.sid = sid

    def hello(self):
        return f"Student {self.name} id={self.sid}"
```

`class Student(Person)` 表示：`Student` 先拥有 `Person` 已有的东西。

`super().__init__(name)` 去执行父类的 `__init__`，让父类把 `name` 存到 `self.name`。下一行再把自己多出来的学号存到 `self.sid`。

如果子类的 `__init__` 里不写这句，对象上就只有 `sid`，没有 `name`。后面用 `self.name` 会报错。

`hello` 在子类里又写了一遍，这叫覆盖。`Student(...).hello()` 走子类这一份。`Person(...).hello()` 仍走父类那份，父类的方法还在。

```python
stu = Student("Qiu", "2026001")
print(stu.name)     # Qiu        ← 父类 __init__ 存的
print(stu.sid)      # 2026001    ← 子类自己存的
print(stu.hello())  # Student Qiu id=2026001
```

## 4. 练习 3 的主程序

输入一行，中间一个空格：

```text
Qiu 2026001
```

```python
name, sid = input().split()
stu = Student(name, sid)
print(stu.hello())
```

`split()` 得到 `["Qiu", "2026001"]`，分别放进 `name` 和 `sid`。学号按字符串留下即可，题目没有要求把它变成整数。

`Student(name, sid)` 做出一个学生对象。`print(stu.hello())` 打印那句自我介绍。

## 5. 创建时实际发生的顺序

以 `Student("Qiu", "2026001")` 为例：

1. Python 新建一个空对象，把它叫做 `self`。
2. 进入 `Student.__init__`，`name` 是 `"Qiu"`，`sid` 是 `"2026001"`。
3. `super().__init__("Qiu")` 进入 `Person.__init__`，执行 `self.name = "Qiu"`。
4. 回到子类，执行 `self.sid = "2026001"`。
5. 这个对象作为 `Student(...)` 的结果交出来，赋给 `stu`。

## 6. 容易写错的地方

- `def hello(self)` 缩进在 `class` 里面。缩进到外面，它就变成一个普通函数，对象调用不到。
- 调用是 `stu.hello()`。写成 `stu.hello(self)` 会多传一个参数。
- 类名 `Student` 是图纸。某个学生的名字在对象上，写 `stu.name`。`Student.name` 取不到 `"Qiu"`。
- 父类 `__init__` 需要的参数，子类要接住并交上去。这里父类要 `name`，所以 `Student.__init__` 也要有 `name`，并写进 `super().__init__(name)`。
