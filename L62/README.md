# L62 数据划分与评估指标：分类

阶段C经典机器学习。本课从“未见数据才是考试卷”出发，完整讲解分层训练/测试划分、泄漏边界、混淆矩阵以及 accuracy、precision、recall、F1。

## 文件
- `notes.md`：五段理论与 coding 双主线讲义，含公式、逐条演练、反例和适用边界
- `examples.py`：可独立运行的手写指标、trace、分层切分、基线/浅树对比及自检
- `homework.md`：3 道机试/笔试风作业和硬验收
- `homework/answers.ipynb`：约 9:30 写标准答案

## 运行
需要 Python、NumPy、scikit-learn：
```bash
python -B L62/examples.py
```
不下载数据，不读写本地文件。程序实测输出：
- 手算例题 `TN=3, FP=1, FN=1, TP=3`，四项指标均为 0.75；
- 全体/训练/测试正类比例均为 0.200；
- 多数类基线矩阵 `[[40,0],[10,0]]`，准确率 0.80、召回率 0；
- 深度3树矩阵 `[[39,1],[4,6]]`，accuracy 0.90、precision 0.857、recall 0.600、F1 0.706；
- 空输入、长度不等、非法标签、无正类预测、ID 不重不漏、矩阵计数与 sklearn 一致性均通过。
