## 学习与运行

先读 notes.md，再运行 examples.py，然后独立完成 homework.md。示例仅使用 Python 内置功能，无额外依赖，无文件写入。

在仓库根目录运行：
```bash
python -B L14/examples.py
```

程序先执行断言，再打印 n=1、2、4、8、16、32 的计数表。n=8 对应扫描比较 7 次、三角位置对 28 次、减半 3 轮。前缀和示例为 [4, 5, 12, 15]。
