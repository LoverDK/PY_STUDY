## 统计口径

- 单项均值与学生普通平均分忽略缺失项。
- 加权分只有在三项成绩齐全时计算。
- 期末通过率只统计有期末成绩的学生。
- 分数必须为数值且位于 0–100，学生编号必须唯一。

## 自检

预期关键结果：

- 三项均值约为 `73.625、70.5、79.0`。
- 期末有效考生通过率为 `85.71%`。
- 期末较期中提高至少 10 分：陈晨、李雷、周航、孙悦。
- 输入 DataFrame 在分析后保持不变。
