# L13 课堂交付稿

## 标题

**NumPy+Pandas 联用小卷（读表→数组统计）**

## 阶段与范围

本课属于阶段 A：DSBA / Python / 可视化 / 复杂度。范围是 CSV 读表、结构校验、DataFrame 选列、数组转换、按轴统计、缺失值与布尔筛选、结果回填。本课不进入数据库、机器学习建模、复杂 Excel 工程，也不涉及计算机系统原理。

## 目标

今天要建立一条可复用的数据分析流水线：Pandas 负责把表读对、把列选对、把标签留住；NumPy 负责把数值矩阵算快、把轴和掩码写清；最后再回到 DataFrame 输出可追溯的结果。

## 五段详讲

### 一、先验证，再统计

读 CSV 后先检查 shape、columns、dtypes、缺失值和唯一键。代码能求出平均数，不等于输入有意义。列缺失、学号重复、分数越界都应在统计前失败，并给出能定位问题的错误信息。路径应由脚本自身位置推导，避免工作目录改变导致找不到文件。

### 二、Pandas 与 NumPy 各司其职

用 Pandas 按 `["quiz", "midterm", "final"]` 选列，再调用 `to_numpy(dtype=float, copy=True)`。这样既保留列选择的业务含义，又得到适合向量化计算的二维数组。不要把姓名列一起转入数组；权重向量的顺序必须与列顺序一致。

### 三、用输出形状理解 axis

成绩矩阵形状是“学生数 × 考试数”。`axis=0` 消去学生轴，得到每项考试一个结果；`axis=1` 消去考试轴，得到每名学生一个结果。判断轴时先问“我想得到几个数”，再用断言核对结果形状。

### 四、缺失值先定口径

NaN 不是自动等于不及格。期末通过率若只统计实际应考者，就要先用 `~np.isnan(final)` 找有效分母，再判断 `>= 60`。多个数组条件用 `&` 或 `|`，每个比较都加括号。全员缺考时还要明确返回 NaN 或抛错，防止除零。

### 五、回填时保持行对应

每名学生的结果长度必须等于原表行数，回填后再整体排序。输出保留 student_id 与 name，才能复核。并列时加 student_id 作为第二排序键，让结果稳定。分析函数使用副本，并以断言确认没有修改调用者的原始表。

## 综合例题

本课读取 8 名学生的三项成绩，计算考试均值、学生普通平均、20%/30%/50% 加权分、期末有效考生通过率，以及期末比期中提高至少 10 分的名单。完整代码在 `examples.py`，数据在 `data/scores.csv`。

## 三道练习摘要

1. **销售表统计**：从 CSV 文本读取季度销售数据，缺失月份按 0 计季度合计，各月均值则忽略缺失。
2. **传感器报告**：按设备计算上报有效率、忽略缺失的平均温度，并找出达到告警阈值的设备。
3. **成绩排名**：校验成绩，计算完整记录的加权分，处理无资格记录，并以稳定规则排名。

每题都给出精确行顺序、数值与缺失值断言，必须独立运行并通过硬验收。
